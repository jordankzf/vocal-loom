VocalLoom is a local Python vocal harmonizer and pitch-correction tool with a Windows GUI and CLI. It takes dry singing, a MIDI score and optional lyrics, then produces tuned solos, duets or four-voice stacks.

Song: Hide and Seek by Imogen Heap. Cover performance: jordankzf. This demo uses the approved final mix. Software licensing is described in the project LICENSE and NOTICE.
